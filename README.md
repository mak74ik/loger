# loger (1073)

Консольная утилита и веб-сервис на порту 1073 (`l-1, o-0, g-7, e-3`) для отслеживания запущенных программ, открытых портов и просмотра логов на сервере.

## Использование в терминале

```bash
loger status       # показать список запущенных программ и портов
loger logs         # поток логов в реальном времени
loger new          # добавить адрес/порт программы
loger add <n> <a>  # быстро добавить программу (например: loger add bot http://127.0.0.1:4040 --port 4040)
loger remove <id>  # удалить программу из списка
loger stop         # остановить фоновый сервис
loger start        # запустить сервис
loger restart      # перезапустить сервис
loger reset        # сбросить добавленные адреса к дефолтным
loger help         # справка по командам
```

## Просмотр через curl

При запросе из терминала утилита отдаёт текстовую таблицу:

```bash
curl http://localhost:1073
```

## Веб-интерфейс

В браузере доступен по адресу: `http://localhost:1073`
Позволяет смотреть запущенные программы, добавлять новые адреса и читать логи.
